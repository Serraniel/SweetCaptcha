# Security policy

Please report vulnerabilities through GitHub's private vulnerability reporting on this repository, not in a public issue.

In scope: token forgery or reuse, challenge replay, bypasses of site binding, secret disclosure, ways to make strict mode read device data, and denial-of-service amplification.

A new way to evade the scoring rules is welcome as a normal issue or pull request. The rules are public on purpose, and evasion is an expected limit rather than a vulnerability. See [the limits in the README](README.md#what-it-does-not-do).
